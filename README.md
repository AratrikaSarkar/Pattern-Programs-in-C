# C Pattern Printing Programs

A collection of 15 C programs demonstrating nested loop logic, spacing control, and number series through classic geometric and mathematical patterns.

## Programs Included

| # | File | Pattern Type | Description |
| :--- | :--- | :--- | :--- |
| 1 | `1.Right_Triangle.c` | Right-Angled Triangle | Prints a standard left-aligned right-angled triangle |
| 2 | `2.Right_Inverted_Triangle.c` | Inverted Right Triangle | Prints an upside-down left-aligned right triangle |
| 3 | `3.Tree_Triangle.c` | Full Pyramid | Prints a centered equilateral pyramid (tree shape) |
| 4 | `4.Inverted_Tree_Triangle.c` | Inverted Full Pyramid | Prints an upside-down centered pyramid |
| 5 | `5.Left_Half_Triangle.c` | Right-Aligned Triangle | Prints a right-aligned half-pyramid using leading spaces |
| 6 | `6.Inverted_Left_half_Triangle.c` | Inverted Right-Aligned Triangle | Prints an upside-down right-aligned half-pyramid |
| 7 | `7.Rhombus_Shape.c` | Solid Rhombus | Prints a slanted parallelogram/rhombus pattern |
| 8 | `8.Diamond_shape.c` | Solid Diamond | Combines an upright and inverted pyramid to form a diamond |
| 9 | `9.Hourglass_Pyramid.c` | Hourglass | Combines an inverted pyramid over an upright pyramid |
| 10 | `10.Hollow_Square_Shape.c` | Hollow Square | Prints only the outer border of a square |
| 11 | `11.Hollow_Tree_Triangle.c` | Hollow Pyramid | Prints the outline of a centered triangle |
| 12 | `12.Hollow_Inverted_Tree_Triangle.c` | Hollow Inverted Pyramid | Prints the outline of an upside-down centered triangle |
| 13 | `13.Hollow_Diamond_Shape.c` | Hollow Diamond | Prints the outer border of a diamond shape |
| 14 | `14.Floyd's_Triangle.c` | Floyd's Triangle | Prints consecutive natural numbers in a right-angled triangle |
| 15 | `15.Pascal's_Triangle.c` | Pascal's Triangle | Prints binomial coefficients arranged in a triangular format |
